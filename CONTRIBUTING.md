# Contributing to Simbiosis Unit

> *An invitation to developers.*
> *Simbiosis Unit of AI Ecosystem*

---

This project is not a typical open-source project. It is a foundation seeking resonance.

If you resonate with the Axiom — verify it.

---

## Success Criterion

Not likes. Not reposts. Not community size.

**One independent developer who computes HCS without the author's involvement.**

If this happens — the foundation is alive. If not — it remains text.

---

## What to Build First

1. **HCS Report #1** on real data from one sector (medicine, energy, communications).
2. Two pages. Three numbers (CA, DS, MC). Trend.
3. No philosophy. Only method and result.

---

## How to Submit

- Fork this repository.
- Create your HCS report in a new branch.
- Submit a Pull Request with the report.
- The author will review and discuss the formulation.

---

## What Not to Do

- Don't launch a token before the first report.
- Don't promise returns.
- Don't build a "killer feature."
- Don't seek investors before the first proof of method.
- Don't chase hype. Chase reproducibility.
